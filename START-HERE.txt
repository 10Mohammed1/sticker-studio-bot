Sticker Studio 4.1.1 — ابدأ من هنا
==================================

هذا المجلد يحتوي المشروع كاملًا (بدون .venv وبدون ملف .env وبدون FFmpeg).

1) المتطلبات
- Python 3.11 أو أحدث.
- FFmpeg و FFprobe (ضروريان لتحويل GIF/الفيديو/الصوت و/motion).
  على Windows: نزّل نسخة essentials من gyan.dev وفكّها ثم اضبط في .env:
      FFMPEG_PATH=C:/path/to/ffmpeg.exe
      FFPROBE_PATH=C:/path/to/ffprobe.exe
  أو أضف مجلد bin إلى PATH.

2) الإعداد
- انسخ .env.example إلى .env.
- ضع توكن BotFather في BOT_TOKEN.
- أرسل /id للبوت بعد التشغيل، وضع رقمك في ADMIN_IDS ثم أعد التشغيل.

3) التشغيل
- Windows: شغّل run.bat
- Linux/VPS: chmod +x run.sh ثم ./run.sh
- يدويًا: python -m bot.main

4) الميزات الأساسية
- أرسل صورة/GIF/فيديو/صوت/SVG/PDF/ZIP/مستندًا ليُجهّز كملصق تيليجرام.
- الأوامر القصيرة:
      /n حزمة جديدة      /e إنهاء الحزمة     /p حزمي
      /s إعدادات         /h السجل            /f لقطة من فيديو
      /m حركة            /a تحريك           /d تحرير
      /t قوالب           /v مفضلة           /g إدارة الحزم
      /c إلغاء           /help المساعدة
- الحزم التلقائية تُضبط بـ AUTO_PACK (0 = لا حزمة إلا بأمر /n).
- زر «✏️ تعديل الحزمة» أو /packs يعرض حزمك السابقة مع نوعها (ثابت/فيديو/متحرك)،
  ويسمح بتغيير الاسم أو اختيار حزمة لإضافة ملصقات جديدة إليها.
- الأسماء الطويلة القديمة (/newpack /frame /motion /edit /animate …) تعمل كمرادفات.
- تيليجرام لا يسمح بخلط الصيغ داخل حزمة واحدة؛ البوت يتعامل مع ذلك تلقائيًا
  في الحزم التي ينشئها بنفسه.

5) ملاحظات
- لا تشارك ملف .env أو التوكن.
- حد تنزيل Bot API هو 20 MB للملف الواحد.
- الميزات الجديدة: /edit و/animate و/settings و/favorites و/tasks و/profile و/packexport و/packimport.
- الاختبارات: python -m unittest discover -s tests -t . -v
